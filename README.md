# HBM — Inside the Stacks That Feed the Tensor Cores

A deep dive into HBM2e/3/3e/4 internals — the eight-die vertical stack, TSVs, channels and pseudo-channels, banks and bank groups, refresh, ECC modes (on-die, side-band, in-line), the HBM PHY, and CoWoS-S/L silicon-interposer packaging. Numbers per generation, what you actually get versus spec sheet, and an interactive bandwidth estimator for real access patterns.
